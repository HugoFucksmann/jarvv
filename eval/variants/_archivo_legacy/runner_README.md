# Variantes de campaña

Las variantes que se crean a partir de una medición van acá: `run_<etapa>_<hipotesis>.ts`. El nombre del archivo (sin `.ts`) debe ser único en todo `eval/variants/` y coincidir con `name`. Dejá la hipótesis en un comentario `// Hipótesis: ...`.

Guía completa: [`docs/evaluacion/PLAN_DE_MEDICION.md`](../../../docs/evaluacion/PLAN_DE_MEDICION.md) §4.
